# 校園平板借用登記系統 (Tablet Reservation System)

專為學校設計的現代化線上平板借用登記與管理平台。採用**「先借用登記，歸還時才註銷登記」**的直觀校園管理流程，老師透過任何瀏覽器（電腦、平板、手機）即可輕鬆登記借用與註銷歸還。

---

## 🌟 核心特色與業務流程對照

### 🔄 核心作業流程：「先借用登記，歸還時註銷」
1. **先借用登記 (Borrow Registration)**：
   - 老師選擇平板車（A~G 車）、選擇欲借平板號碼（或一鍵整車借用）、選擇節次與借用時間，送出後即刻完成借用登記。
   - 登記後，平板立即標記為 **【借出使用中】**，並在該時段自動鎖定反灰，其他老師不可重複借用。
2. **歸還時才註銷登記 (Return & Check-in)**：
   - 老師上完課將平板推回設備室時，點入頂部導航的 **【歸還註銷】** 專區。
   - 系統即時列出全校所有「借出待註銷」的單據，找到自己登記的單據後，點擊 **【確認歸還並註銷登記】**。
   - 彈出設備清點確認視窗（平板入車點收齊全、線材配件正常），點選確認後**立即註銷登記**，平板瞬間解鎖釋放回庫存，供下一位老師借用！

## 📋 功能清單與特色

1. **選擇平板車**：
   - 支援 **A、B、C、D、E、F、G 等多台行動平板車**，管理員亦可自訂名稱（如自然科A車）與數量。
   - 卡片式一鍵切換，即時計算每台車當前時段的剩餘可用平板數量。

2. **選擇平板編號**：
   - 預設提供 **01 ~ 27 號與 30 號（每車共 28 台）** 矩陣按鈕，亦可自訂台數（如 01~30）。
   - 提供 **「⚡ 整車借用 (全選)」** 快捷按鈕，一鍵借用整台平板車。

3. **借用日期與時間**：
   - 直觀日曆選擇器（預設當天）與起訖時間選擇。

4. **快捷節次選擇**：
   - 包含：**早自修、第一節、第二節、第三節、第四節、中午、第五節、第六節、第七節、課後、整天** 等標準學校節次。
   - 點擊任一節次會自動帶入標準上下課起訖時間，亦可手動微調。

5. **歸還註銷專區 (Return & Check-in)**：
   - 專屬獨立分頁，即時呈現目前在外借用中的所有平板車與單據。
   - 提供借出待註銷單數與平板總數即時統計、關鍵字快速搜尋、一鍵註銷歸還彈窗。

6. **即時防衝堂檢查 (Conflict Detection)**：
   - 當老師切換日期、節次或時間時，系統自動掃描所有借用資料。
   - **凡借出尚未歸還註銷之平板，自動紅色斜紋鎖定並提示「借出使用中，尚未歸還註銷」**，徹底杜絕撞期與重複借出。

7. **各車借用課表看板 (Schedule Matrix)**：
   - 橫軸為各平板車、縱軸為各節次，全校老師可一目了然看見各時段被哪位老師借用中。
   - 支援向前／向後切換日期與點選空閒格子快速登記。

8. **借還歷史紀錄**：
   - 即時清單、關鍵字搜尋（姓名、班級、車輛）、狀態篩選（借出中/已歸還註銷）。
   - 支援匯出含 UTF-8 BOM 的 **Excel / CSV 借還報表**。

9. **後台密碼防護與管理員自訂設定**：
   - **進入「後台管理」必須輸入密碼驗證**（預設密碼為 `admin123`），保障校園資產管理安全。
   - **🚗 平板車輛與數量管理**：可新增、編輯、刪除平板車，自訂名稱與台數（如 01~30 台）。
   - **⏰ 各節課作息時間管理**：可調整各節開始與結束時間，或新增自訂節次。
   - 隨時可點擊【修改密碼】與【登出管理員】。

10. **Google 試算表免伺服器雲端同步 (Google Sheets Integration)**：
   - 學校無需花錢購買伺服器主機，只要將隨附的 `google_apps_script.js` 部署至 Google 雲端硬碟，即可實現全校多人即時同步。

## 🔒 跨裝置永久儲存設定（徹底解決設定丟失問題）

本系統提供兩大儲存機制，確保在 GitHub Pages 或學校網頁伺服器上時，所有老師的裝置都能讀取到管理員的專屬設定：

1. **方式一：Google 試算表雲端雙向同步（即時全校自動連線，最推薦）**：
   - 管理員在後台修改平板車名稱、台數或節次作息後，系統會**自動即時上傳到 Google 試算表的「系統設定」工作表**。
   - 任何老師只要打開網頁，系統就會在背景自動從雲端載入全校最新的車輛與時間，實現跨手機、跨電腦即時同步！
2. **方式二：產生 `config.js` 全域預設檔（GitHub Pages 靜態部署必備）**：
   - 進入【後台管理】，點擊右上角的綠色按鈕 **【產生 config.js (GitHub 必備)】**。
   - 點擊【一鍵複製完整程式碼】，將內容貼上覆蓋本機資料夾中的 `config.js`。
   - 將修改後的 `config.js` 推送或上傳至 GitHub，全校所有裝置打開都會預設載入您的設定！

## 🚀 如何立即開始使用？

### 方式一：本機 / 校內電腦直接開啟
直接雙擊點開 `index.html`（或使用 Chrome、Edge 瀏覽器開啟），系統已內建測試示範資料，立刻就能操作借用、查看看板與測試防衝堂功能！

### 方式二：佈署為校內雲端服務（建議）
1. 將本資料夾整包放至學校的網頁伺服器、NAS Web 資料夾，或免費託管至 GitHub Pages / Vercel / Netlify。
2. 參考下方說明串接 Google 試算表，老師只要開啟學校配發的網址即可登記。

---

## ☁️ Google 試算表雲端串接設定 (3 分鐘完成)

1. 開啟 [Google 試算表](https://sheets.google.com)，新建一個試算表，命名為「平板借用登記表」。
2. 點擊頂部功能表的【擴充功能】→【Apps Script】。
3. 清空編輯器內的原本代碼，將 `google_apps_script.js` 的完整內容貼入。
4. 點選右上角的【部署】→【新增部署作業】。
5. 齒輪圖示選擇【網頁應用程式】(Web App)：
   - **誰可以存取**：務必選【任何人】(Anyone)。
6. 點擊【部署】，複製產生的「網頁應用程式網址」(以 `/exec` 結尾)。
7. 回到本系統網頁的【後台管理】頁面，貼入該網址並點擊【儲存雲端設定】即完成串接！
